# HTML Resume Template

A clean, single-page **HTML resume template** - opens in any browser, prints perfectly to PDF. Apache-2.0 licensed.

## ✨ Features
- Single-page responsive design
- Print-ready (browser → PDF)
- No dependencies, pure HTML + CSS
- Mobile-friendly

## 🚀 Usage
1. Download or clone this repo
2. Edit `resume.html` with your info
3. Open in browser → Print → Save as PDF
